# LIGHTNESS

This repository contains an Android app that lets you:
- record a 2-second voice clip automatically
- boost audio from 1x to 10000x
- play boosted audio from files
- use a red/dark UI

Important:
- This is a speaker-output audio booster app.
- It does not override live Discord microphone input on a normal unrooted Android device.
- For true live Discord mic boosting on Android, use a PC audio mixer, external mic, or rooted/advanced audio setup.

## Open in Android Studio
1. Download the ZIP from GitHub.
2. Extract it.
3. Open the folder in Android Studio.
4. Let Gradle sync finish.
5. Connect a device and press Run.
